Robótica

Fotos e vídeos dos robôs, circuitos e protótipos montados em sala. Cada projeto entra aqui com uma legenda curta.

GALERIA — ROBÓTICA

Como adicionar fotos/vídeos aqui: abra o arquivo index.html, procure a lista MEDIA.robotica no final do arquivo e adicione um item como { type: 'image', src: 'assets/robotica/nome-do-arquivo.jpg', caption: 'legenda curta' }. Coloque o arquivo de foto/vídeo dentro de uma pasta chamada assets/robotica/, ao lado deste HTML.
